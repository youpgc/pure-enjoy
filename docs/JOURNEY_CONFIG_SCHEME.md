## 0. 通用公式（固定，不做脚踩脚连乘）

### 0.1 伤害公式（先基础值，后百分比，加法合流）

```
基础值 = 角色基础攻击(base_attack) + 等级攻击(+12/级) + 攻击卡(+30/次，累计≤1200)
       + 法宝品阶伤害(weapon_levels[min(角色等级,8)]，缺行回落 base_damage)

增伤Σ% = 攻击力%(锐金本源 +3%/层，≤8 层)                      ← 攻击力%桶 attackAmp
       + 武器增伤%(离火本源 +3%/层 + 化形枝金/火点亮 +5%/层
         + 舍利子 +15% + 红孩儿光环 +8% + 局内伤害槽 +20%/级，
         整桶钳 ≤ +200%)                                       ← 武器增伤%桶 damageAmp
       + 紫金葫芦叠层 +3%/层（击杀精英/妖王 +1 层）
       + 三头六臂窗口 +40%（哪吒特殊能力，增益期）

单次命中 = 基础值 × (1 + Σ%)        ← 单次乘算
暴击命中 = 单次命中 × 暴击伤害(基准 150%，钳 [100%, 200%])
灼烧/反伤/闪电链等衍生伤害不吃增伤%、不受益于破甲（口径已闭环）
```

### 0.2 护甲减伤与破甲（双轨）

```
减伤比例 = armor / (armor + K)，K = 80（journey_globals.armor_curve_k 可配）
玩家侧上限 60%；怪物侧上限 72%（monster_armor_reduction_cap 可配）
参考减伤：20甲20.0% · 25≈23.8% · 40≈33.3% · 50≈38.5% · 80=50% · 100≈55.6%
         · 120=60% · 150≈65.2% · 180≈69.2% · 200≈71.4%

破甲（穿刺槽）：有效护甲 = 护甲 × (1 − 无视比例)
无视比例 = 10% + 2.5%/级，9 级 = 30%，硬上限 30%
```

### 0.3 吸血

```
单次回复 = max(最终命中伤害 × 比例, 2 点)
比例 = 3% + 1.5%/级（9 级 15%），钳 ≤ 20%
每秒合计 ≤ 最大生命 10%（1 秒滑窗）
```

### 0.4 怪物强度乘区（不放大护甲）

```
mult = 1 + 对局分钟 × 0.30(时间斜率) + 关卡难度 × 0.04，钳 ≤ 6.0
怪物血量 × mult；移速 × mult 后钳 ≤ 200 px/s；
接触伤害 × (0.85 + mult × 0.2)（mult=6 时最高 ×2.05）
```

### 0.5 妖王专项曲线

```
妖王血量 = base_hp × [1 + 对局分钟 × 0.30 × 0.50]（只随时间，不吃难度项）
妖王接触伤害 = base × [1 + (玩家等级−1) × 0.15]（与玩家生命成长同频，不稀释压力比）
妖王降临延迟 300 秒；降临倒计时全程可见；阵亡→复活冷却 10 秒
（boss_spawn_delay_sec / boss_warn_sec / boss_respawn_cd_sec 后台可配）
```

### 0.6 经验与等级

```
升级所需经验 = 12 + 当前等级 × 7（exp_base / exp_per_lv 可配）
角色等级上限 99（满级经验条恒满）；法宝品阶取 min(角色等级, 8) 档

无尽妖潮（独立曲线，globals 的 endless_exp_base/per_lv/pow 可配）：
  升级需求 = endless_exp_base + endless_exp_per_lv × 当前等级^endless_exp_pow
           = 12 + 28 × lv^1.75（默认标定：波 17≈17 级、第 81 波满级）
  经验产出 = 经验基准 ×(1+强度乘区×exp_mult_k) ×波次成长乘区
            ×发育期倍率（仅发育波）
  波次成长乘区 = 1 + exp_wave_gain ×(波号−1)（默认 0.02）
    · 普通怪基准=自身 exp_drop；精英怪基准=自身 exp_drop（分档）
    · 妖王基准=boss_exp_base（默认 200，脱离「限血选怪」锁死的低血档表值）
    · 三类怪共享波次成长乘区，整池随波扩张——修复旧口径「需求二次、
      产出线性、妖王被锁低档」导致的 17 波前后卡级；0=还原旧口径。
```

### 0.7 暴击

```
暴击率：老君光环 +5%(基础) + 局外天赋(离火生息 +1.5%/层≤5 层) + 局内暴击槽，引擎钳 ≤ 60%
暴击伤害：基准 150% + 天赋(锐金生息 +5%/层≤5 层) + 老君光环 +20% + 局内暴伤槽 +6%/级，钳 ≤ 200%
```

## 4. 法宝（9，journey_weapons + journey_weapon_levels）

角色专属 4 件走环绕底盘（`attack_kind=orbit`）；常规 5 件按 `attack_kind` 作为并行单位，且**只挂当前出战角色自己的那件法宝**——法宝归属角色，换人出战即换一件，其他角色的法宝不再常驻并行（概念设计 §21）。出战扩展角色时法宝在环绕底盘之外叠加一份对应形态的并行攻击（环绕加领域）；出战取经四角色时法宝为 orbit 型，只有环绕、无并行单位。`attack_kind` 决定行为，`journey_weapon_levels` 分级列按形态消费：`orbit→damage`、`projectile→interval_ms+proj_count+damage`、`boomerang→interval_ms+damage`、`aura→value_num`、`beam→interval_ms+damage`、`magnet→value_num`。分级取值 = `min(角色等级,8)` 级，缺列回落 `journey_weapons` base 列（base_interval_ms/projectile_speed/pierce），全部后台可配。紫金葫芦剥离回血后，引擎不再消费 `heal_amount`/`heal_fixed` 两列（后台列保留、仅不再生效）。领域范围取武器臂展长度，不再消费 `aoe_radius`。

### 灼烧触发口径（全来源统一）
所有灼烧（武器灼烧槽、兜率炉火、阴阳二气瓶）不再由武器命中点燃，统一改为：怪处于武器外环圆内（整圆距离判定，不看扇叶角度/命中冷却）累计驻留时长，满 `weapon.burn_dwell_sec`（默认 1 秒）即点燃全部当前生效来源，此后每满一个阈值续燃一次、无限续烧；离开范围清零驻留计时，重新进入需再次驻留满阈值。各来源伤害口径不变（灼烧槽固定值型绕甲、炉火与二气瓶按武器伤害比例经甲，已点燃来源按各自时长独立烧完）。阴阳二气瓶的定身仍按其 18 秒周期触发，只有灼烧并入驻留判定。

> 该阈值在后台「西行配置 → 战斗参数 → 武器与吸血穿刺 → 命中冷却与灼烧驻留」的「灼烧驻留触发(秒)」逐键可改（`journey_battle_params.weapon.burn_dwell_sec`，缺省回落 1 秒）。

> 并行攻击单位（非常规 attack_kind 的已解锁法宝）分两轨：**弹道轨**（穿透弹/回旋/光束）与环绕武器走同一伤害公式乘区（基础值→(1+增伤Σ%)、暴击同源、破甲经甲），按各自攻击动作命中，携带法宝自身初始特效，击退/吸血与全局维度槽取较高等级，灼烧型按命中点燃并使用独立 source key（`attack_<code>`）；**领域轨**（八卦炉真火 aura/紫金葫芦 magnet）走独立真实伤害乘区，范围=武器臂展长度，两条结算线：①驻留伤害——范围内全部怪按驻留时间每满 1 秒结算一次 `value_num（领域每秒伤害基准）×驻留倍率` 真实伤害，不限目标数；②周期脉冲——每 1.5 秒以领域内每只怪为起点向外扩散 `臂长×0.3` 的圆，波及圆内全部怪（含臂展外）各结算一次 `value_num ×驻留倍率` 真实伤害，同怪每次脉冲至多中一次。驻留倍率 = 1 + 连续驻留秒数/达上限秒数 ×(封顶倍率−1)，离开范围清零重算——驻留越久伤害越高，满配基准 337×封顶 6 倍≈2023/秒。领域伤害不叠加角色基础攻击/等级攻击/增伤百分比，不受护甲减免，不触发暴击/雷引/紫金铃/伏魔等环绕专属效果。火眼金睛对精英/妖王的条件增伤并入增伤百分比合计（Σ%），随走伤害公式的命中生效。
>
> 吸血边界：吸血（吸血维度槽 + 初始特效）只在武器环绕命中与弹道命中（走 `_hitMonster`）触发；领域伤害与灼烧伤害都不触发吸血或回血，紫金葫芦领域不再回血。灼烧按来源独立结算、互不相加：武器维度槽灼烧（`weapon_burn`，固定值型真实伤害）与八卦炉法宝灼烧（`field_sanmei_fire`，按领域 `value_num` 固定基准比例的真实伤害）分属两条链路，各自按独立 source key 计时、各自扣血；两种灼烧都不随驻留递增，武器灼烧槽数值 = 槽值×槽等级×(1+(角色等级−1)×等级成长系数)，领域灼烧数值 = `value_num × attack_burn_ratio`，驻留倍率只作用于领域直伤、不影响灼烧，保证后期仍有效。领域灼烧 source key 用 `field_<code>` 前缀，与弹道灼烧 `attack_<code>` 前缀分开，切换攻击形态不覆盖旧来源口径。相关后台键：`journey_battle_params.weapon.field_pulse_period_sec`（领域脉冲周期秒，默认 1.5）、`field_pulse_radius_ratio`（脉冲扩散半径相对臂长比例，默认 0.3）、`field_dwell_cap_mult`（驻留封顶倍率，默认 6）、`field_dwell_cap_sec`（驻留达封顶秒数，默认 6）、`burn_level_growth`（灼烧等级成长，默认 0.04）、`attack_burn_ratio`（法宝灼烧伤害比例，默认 0.25，弹道=命中伤害×比例、领域=每秒伤害基准×比例）、`attack_burn_sec`（法宝灼烧持续时间秒，默认 2，各来源独立计时）、`attack_target_cap`（弹道单次目标上限，默认 3）、`attack_shot_life_sec`（弹体存在时间上限秒，默认 8，超时强制销毁兜底异常射程/速度）。

**负面态口径**：致盲削减对妖伤害、套取削减增伤（乘算，不被增伤上限吞掉）；破甲仅降玩家护甲（曲线与上限不变）；减速只影响摇杆移动，不影响强制位移与技能牵引；封印期内该槽等级按 0 计，槽定义与 UI 不变；毒刺窗口内未续层自动清零。终局与还魂会清空在途弹道/预警/领域及全部负面态。

**闭环细则**：
- **GCD 只约束真正起手的主动技**：纯血线被动（法天象地）不进周期调度，狂暴期的九头噬在非狂暴段停表等待，二者都不空写 GCD 挡住冲撞；定身/超射程时条件不满足不空转。
- **假身只是一张承伤皮**：变化术/分瓣梅花召出的假身沿用本体模型，但不施法、不冲撞、不战斗中回血、不占大血条、死亡不触发分裂/法天象地与击杀结算，避免递归召身。
- **持续伤害单通道整体覆盖**：多个领域的 DOT 不在同通道叠加，按「每跳伤害×持续秒数」取总量更大者整体替换，杜绝跨来源拼出不存在的强度；换源/到期/还魂均归零跳伤节拍。
- **火系伤害吃辟火罩**：三昧真火的预警落地走火伤通道，先过辟火罩减免再进护甲与最终减伤区；落雷/突刺等非火技能不受影响。
- **领域判定节拍有下限**：后台配置的领域 tick 钳到 0.1~60 秒，避免 0 或负值造成逐帧高频结算。
- **强度数值全部后台可调**：领域判定间隔（`mist_tick`/`prison_tick`/`thorn_tick`/`trap_tick`/`frost_tick`/`bell_tick`/`blade_tick`）、弹体存活与尺寸（`fang_life`/`fang_radius`/`core_life`）、时序（`fire_first_delay`/`thunder_gap`）、假身散布（`decoy_ring`/`decoy_ring_jitter`/`decoy_angle_jitter`）均为逐怪参数，默认值仅作未配置兜底，种子见 §12.1 对应 SQL。
- **不可配的是机制常量**：对象池上限（弹道 48/预警 24/领域 16）、减伤/破甲防呆钳（≤0.9）、tick 安全钳（0.1~60 秒）等保护性边界不开放后台，避免误配击穿结算或撑爆渲染。
- **护盾攻防同基准**：照妖镜反震与震妖钟震荡都取「减伤前原值」——护甲曲线、最终减伤区、护盾抵扣之前的到手伤害；反震直接对来源妖物结算并无视护甲，震荡对范围内全部妖物结算（是否无视护甲由 burst_armor_ignore 决定）。二者只在护盾真正抵扣（反震）或护盾归零（震荡）时触发，无敌帧内不触发。
- **破盾能力只改系数不改管线**：带盾受伤加成在玩家受击入口对进入伤害乘算，反震衰减在反震结算处乘算；撕盾走独立的护盾扣减入口并复用盾破震荡钩子，避免与常规受击的盾破判定重复触发。护盾溢出转化、套装与妖王专属变体均不实现。
- **施法者死亡即清场**：妖王被击杀时清掉它在途的弹道/预警/领域，不会出现「杀死妖王仍被其延迟技命中」；还魂同样清空在途技能与全部负面态（含禁疗）。
- **领域的施法者归属独立记录**：固定落点领域也携带 owner，确保 `slow_sec` 等逐怪参数能读到配置；位置跟随（冰霜领域）单独用 follow 标记，两者解耦。
- **真伤只过护盾**：毒刺满层爆发等真伤跳过最终减伤区（金刚/光环），仅由护盾抵扣，与「绕甲真伤」口径一致。
- **穿透弹道命中去重**：同一目标对单颗弹道只结算一次，避免停留碰撞圈内逐帧扣血。
- **DOT 跳伤节拍后台可调**：`boss.skill_dot_tick`（默认 1 秒，钳 0.1~60 秒），毒雾/灼烧领域统一按该节拍结算。
