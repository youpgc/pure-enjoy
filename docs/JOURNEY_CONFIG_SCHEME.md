## 0. 通用公式（固定，不做脚踩脚连乘）

### 0.1 伤害公式（先基础值，后百分比，加法合流）

```
基础值 = 角色基础攻击(base_attack) + 等级攻击(+12/级) + 攻击卡(+50/次，累计≤500)
       + 法宝品阶伤害(weapon_levels[min(角色等级,8)]，缺行回落 base_damage)

增伤Σ% = 攻击力%(锐金本源 +3%/层，≤8 层)                      ← 攻击力%桶 attackAmp
       + 武器增伤%(离火本源 +3%/层 + 化形枝金/火点亮 +5%/层
         + 舍利子 +15% + 红孩儿光环 +8% + 局内伤害槽 +20%/级，
         整桶钳 ≤ +200%)                                       ← 武器增伤%桶 damageAmp
       + 紫金葫芦叠层 +3%/层（击杀精英/妖王 +1 层）
       + 三头六臂窗口 +40%（哪吒特殊能力，增益期）

单次命中 = 基础值 × (1 + Σ%)        ← 单次乘算
暴击命中 = 单次命中 × 暴击伤害(基准 150%，钳 [100%, 200%])
灼烧/反伤/闪电链等衍生伤害不吃增伤%、不受益于破甲（口径已闭环）
```

### 0.2 护甲减伤与破甲（双轨）

```
减伤比例 = armor / (armor + K)，K = 80（journey_globals.armor_curve_k 可配）
玩家侧上限 60%；怪物侧上限 72%（monster_armor_reduction_cap 可配）
参考减伤：20甲20.0% · 25≈23.8% · 40≈33.3% · 50≈38.5% · 80=50% · 100≈55.6%
         · 120=60% · 150≈65.2% · 180≈69.2% · 200≈71.4%

破甲（穿刺槽）：有效护甲 = 护甲 × (1 − 无视比例)
无视比例 = 10% + 2.5%/级，9 级 = 30%，硬上限 30%
```

### 0.3 吸血

```
单次回复 = max(最终命中伤害 × 比例, 2 点)
比例 = 3% + 1.5%/级（9 级 15%），钳 ≤ 20%
每秒合计 ≤ 最大生命 10%（1 秒滑窗）
```

### 0.4 怪物强度乘区（不放大护甲）

```
mult = 1 + 对局分钟 × 0.30(时间斜率) + 关卡难度 × 0.04，钳 ≤ 6.0
怪物血量 × mult；移速 × mult 后钳 ≤ 200 px/s；
接触伤害 × (0.85 + mult × 0.2)（mult=6 时最高 ×2.05）
```

### 0.5 妖王专项曲线

```
妖王血量 = base_hp × [1 + 对局分钟 × 0.30 × 0.50]（只随时间，不吃难度项）
妖王接触伤害 = base × [1 + (玩家等级−1) × 0.15]（与玩家生命成长同频，不稀释压力比）
妖王降临延迟 300 秒；降临倒计时全程可见；阵亡→复活冷却 10 秒
（boss_spawn_delay_sec / boss_warn_sec / boss_respawn_cd_sec 后台可配）
```

### 0.6 经验与等级

```
升级所需经验 = 12 + 当前等级 × 7（exp_base / exp_per_lv 可配）
角色等级上限 99（满级经验条恒满）；法宝品阶取 min(角色等级, 8) 档
```

### 0.7 暴击

```
暴击率：局外天赋(离火生息 +1.5%/层≤5 层) + 局内暴击槽，引擎钳 ≤ 60%
暴击伤害：基准 150% + 天赋(锐金生息 +5%/层≤5 层) + 老君光环 +20% + 局内暴伤槽 +6%/级，钳 ≤ 200%
```
