# 宠物模块需求标准（定版）

本档记录宠物模块**已拍板的需求口径**，是后续迭代的变更基线：改数值/口径须先更新本档再动代码。
本期定版范围：经济锚点 / 成长曲线（含 20261025 增档 100）/ 地图体系（含星穹·源初新阶）/ 健康循环 / 任务 / 成就（含收藏系与圆满彩蛋）/ 道具与掉落（含收藏兑换）/ 抽奖 / 扩容增档 / 文案与展示标准 / 双端同步标准 / 服务端变更流程。

---

## 1. 经济锚点

- **蛋价四档**：N=3600 / R=12000 / SR=26000 / SSR=50000 金币。
  节奏依据：以「最大金币产出速率」计，SSR 需积攒 28 天、SR 14 天、R 7 天、N 2 天。
- **幸运蛋礼盒（抽奖）**：30000 金币/次，SSR 2%，有终身与时段限购（后台 `reserved.lottery` 配置）。
  商城卡片只出营销文案（如「有机会抽中传说级宠物！」），按钮只标价格；机制与概率数字仅在概率公示页，问号入口可达。

## 2. 成长曲线

- **升级经验 = 查表定版**（`pet_config.level_exp_table`，99 项 L1~99，Admin 可调）：
  每级耗时**严格前快后慢**；常规游玩约 365 天到 90 级，高强度约 91 天；L90~99 为增档段（沿尾部 +2.9%/级：L90 需 111,611 → L99 需 144,423）。
- **等级上限 100**（20261025 增档）：`level_max` 与经验表同调，增档 = 只改配置不动代码。
- 取值三级：查表 → 公式（`base × growth^(level-1)`）回退 → 旧 /100 展示兜底；两端同源（summary config 下发）。
- **经验银行**：到上限后经验继续累积不冻结；上调 `level_max` + 补表即按存量自动连升（连升级照发属性点、照写升级时间线）；下次增档同机制。
- **每升 1 级发 `levelup_attr_points`（默认 2）可分配属性点**（`_pet_add_progress` 发放，存量已按「(level-1)×2 − 已分配」回补）。
- 旧版客户端无查表能力，按公式显示升级需求（与服务端表不一致）——服务端结算是唯一真源，旧版进度显示偏差属预期，升级以服务端为准。

## 3. 地图体系

- **72+8 图 · 20 阶**（20261025 增档）：每 5 级一阶。19 阶**星穹**（Lv90：坠星原野/银河渡口/观星塔顶/寂灭星环）+ 20 阶**源初**（Lv95：晨曦之海/万物苗床/第一缕光/终焉之门），经验/金币基数沿 18 阶 +12%/阶插值，长途独占与保底同高阶口径；在售图共 98（含 18 秘境）。
- **属性要求口径（✅ 20261027~28 三批定版，SQL 均已执行归档）**：
  - **达标语义**：属性要求全满足 = 必不遇险；未达标仍可出发但保留遇险判定（未达标项 App 红显「有遇险风险」）；
  - **阶段内轮转**：4 图属性组合按阶段内位次取模 4 轮转（1 维图轮四维、2 维图轮配对 力耐→耐敏→敏智→智力），阶段内保证 ≥3 种组合，任意流派都有可安全游历的图；
  - **数值按加点预算锚定（总需求 ≤ 2×曲线）**：曲线 = `round(10+(解锁等级−1)×0.9)` 随加点 2/级走——1 维图 = 曲线、2 维图两维各 = 曲线、**3 维图 = 高位一维曲线 + 两个次位曲线/2**（高位随轮转各占一图，如 Lv90：{90,45,45}）；任意评级宠物以其主维为高位的那张图必可达，杜绝「每维恒统一值导致高阶三维图永不可达」；
  - 维度分相：前期 1 维 / 中期 2 维 / 后期 3 维（维度数维持各地现状）。
- **扩容增档**（20261025）：背包 22→28（VII~IX：1700/2400/3200）、养育 5→8（V~VII：3200/6400/12800）、寄养 10→16（VI~VIII：3200/6400/12800），价格沿各自涨价曲线；购买链路复用 `buy_expansion`（活配置钳上限+步序防跳档），App 阶梯过滤零改动。
- **时长奖励系数**（`adventure_tier_mult`，Admin 可调）：经验 **1 / 3 / 6**、金币 1 / 2.5 / 8、道具 1 / 1.2 / 1.5。
  设计哲学：经验轨与金币轨同构——**短途单位时间最赚（升级主粮），长途单次总量最大 + 稀有掉落（寻宝之旅）**。
  经验系数按定版节奏表重标（20261025 方案 B）；三档系数是一套时间比例体系，**禁止只调单档**造成每分钟效率阶梯倒挂。
- **隐藏秘境**（每系 1 图，共 18）：
  - 解锁钥匙 = 星辰罗盘（0.4% 长途掉落、80 次保底）；App 点锁定卡 → 确认弹窗 → 消耗罗盘解锁；
  - **未解锁前名称保密**（卡片只显示「未解锁的秘境」+ 收藏暗示 + 需求等级，左侧星星图标、右侧锁标）；
  - **不入推荐池**：「为你匹配」只推普通图——秘境的发现权在用户手里的罗盘，不靠系统带路（服务端 match 三处查询过滤 + App 侧双保险）。

## 4. 健康循环

- 饱食/心情**持续衰减**（历险中也衰减，寄养冻结）；展示层 60s 插值近似，服务端惰性结算为准。
- 健康：历险失败惩罚扣减；非 danger 结果归来回血（`adventure_health_recover`，默认 10）；
  **虚弱阈值 = 历险出发门槛**（默认 20），低于阈值 UI 红显、禁止出发。

## 5. 任务

- **生态分层（20261026 定版）**：日常 = 零成本高频 5 类（喂养/互动/历险/清洁/玩耍）；每周 = 有成本或冷却动作（孵化/繁育/进化/治疗/装扮/兑换/长途历险）。
- **下发条件（eligibility）**：后期任务只下发给具备前置的玩家——繁育=已解锁繁育功能；孵化=累计孵化≥3 只；进化=存在宠物**即将进入进化**（{"evo_ready":true}：下一阶存在且目标开放、等级未达标但差距在 7 天常规成长窗口内——20261026 定版（按评级分档）：一阶 **N28/R30/SR32/SSR35**、二阶 **N58/R61/SR64/SSR68**（链内形态评级与基础形一致，按目标形态评级分档；成长阶段语义=幼年→成长→成年铺满旅程）；窗口为**经验差口径**——距需求等级剩余经验 ≤ evo_quest_window_exp（默认 2600≈7 天常规日入），任意曲线深度自适应；已达标的不匹配——达标即进化、单宠最多 2 次，匹配存量会把任务发给即将无宠可进的玩家）。抽取时过滤，抽不到即无「挂死任务」。条件六类（20261026 对齐）：功能已解锁 / 背包持有 / 累计行为 / 进化窗口（evo_ready 经验差）/ 场景有货（scene_available 有在售主题未解锁）/ 积分充足（points_enough ≥1 金币兑换额）/ 存在伤员（any_damaged 有健康未满的养育宠——任务出现时治疗本就有价值；道具价与任务奖励均为运营可调数据，判定不依赖任何价格常量）。
- **目标定标**：历险 4/10/20（普通/进阶/困难，金币 12/25/40；理论上限单格 48 次/天、5 格 240 次留给成就累计线）；互动 5/12/25（抚摸不限次为既定口径——20261021 拍板：次数仅统计、亲密度日上限自然封顶；任务定标按合理游玩频次不贴上限）；喂养 1~8、清洁/玩耍 1~3（困难档奖励回送同类道具自给闭环）。
- **历险进度按事实表实况重算**（领取/失败归来即计数，支持条件时长过滤如「长途 2 次」；抽取后回填当日已完成的历险数）——天然幂等不丢计。
- **健康生态（20261026）**：饱食/心情归零 → 健康停止恢复并缓降（reserved.low_status_health_decay 默认 2/小时，降至虚弱线 20 停止）；清洁浴球附带回血 5 点（effect.health 键）。治疗任务在每周池（1 次/200 金）。
- 周任务进度从**本周首次打开页签**起算，之前的行为不追溯（口径已写入用户文案）。

## 6. 成就

- **体系树**（bronze/silver/gold/legend 阶进，现网 **42 节点**）+ 扁平一次性成就（memorial/epic/legendary）共存；新增树节点后目标值随之增长（十全十美动态口径兼容）。
- **渐进揭示**：前置未全部领取的节点不进列表（服务端 `PET_ACH_PREREQ_LOCKED` 兜底）。
- **运营约束**：停用任一成就树节点会使「十全十美」不可达（目标=全树节点数）——停用前须重跑 `fix_pet_collection_sink` 重算目标或恢复节点。
- **已领取的成就继续展示累计进度**（只增不减，进度快照落库）。

## 7. 道具与掉落

- 食物/治疗**按阶段步进**：进阶粮 80 / 珍馐盛宴 200 / 急救包 300（回 60 健康）/ 治愈圣泉 600（全满）；加速剂小 10 / 大 40 金。
- **掉落条目两种合法格式**：`{code,min,max,p}` 区间随机；`{p,code}` = **固定 1 件**（服务端缺省 1，不回错误）。
- **常规道具概率乘独立的 items 时长系数**（`adventure_tier_mult.items`：short=1 / medium=1.2 / long=1.5，Admin 可调，封顶 0.9）——**禁止蹭经验系数**（长途经验系数 24× 会把一切顶到封顶=必掉）。
- **掉落率基线（20261024 全线 ×0.4 定版）**：常规道具 0.25/0.10 → 0.10/0.04；星辰罗盘 1% → **0.4%**、凡品石 1.2%、珍品石 0.8%、极品石 0.4%、收藏品 2%。长途单宠单次期望：常规道具 ≈17%、罗盘 0.4%。
- **价格体系（20261026 重定标，跟随金币日入 300~1500 生态）**：口粮 40~400 / 清洁 35 / 玩耍 60 / 治疗 500~2200 / 加速剂 30/120 / 更名卡 300 / 救援绳 250 / 洗练剂 400/350 / 进化石 400/1200/3000（商城=省时溢价，肝价见掉落基线）/ 双倍经验药 1500 / **主题买断万级起**（草甸 10000、星海 18000，App 主题面板带整屏预览）。
- **任务奖励通胀（20261026）**：日常按难度 15/30/50 金、周任务按难度 250/400/600 金（道具分量另计）。
- **价格动态原则（20261026）**：道具价格与任务奖励均为 pet_items/pet_quests 运营数据，随时可调——**代码与判定逻辑禁止出现价格常量**；经济类判定只允许用配置键或实况查询（积分兑换额走 points_per_gold、治疗资格走伤员实况）。
- **保底口径**：保底次数**不随概率缩放**，长途稀有一律 80 次未中必得；各道具独立计数，命中或达保底即得，得后清零重计。
- **积分只经「积分兑换」渠道产出**——随机事件奖励不含积分项（Admin 编辑器无积分字段）。
- **收藏品消费端（收藏兑换）**：`reserved.collection_exchange` 配方表（Admin 可调），六系收藏品各 3 档：**4 件→双倍经验药 / 6 件→进化石·极品 / 10 件→星辰罗盘**——收藏品是终极货币，罗盘可换 = 隐秘境自循环的稳定终点。App 商城在持有收藏品时出兑换卡；`rpc_pet_collection_exchange`：配方/持有/满包预检三道校验（满包不扣料），扣料入包走道具流水。
- **防刷口径**：`collection_total` 只计 `biz_type='acquire'` 的收藏品流水——兑换的 consume/exchange 流水不计数，收藏品兑走不减累计。
- **收藏/圆满成就**：`collection_total`（累计获得收藏品件数，流水口径）——3 件「初代收藏家」(epic：500 金+双倍药) / 10 件「秘境鉴赏家」(legendary：3000 金+极品石)；`tree_full_claim`（成就树已领节点数）——全部领取「十全十美」(memorial：10000 金+传说蛋，跨线彩蛋；目标=全树节点实际数现网 42，动态口径)。
- **珍稀保护（丢物边界三规则）**：`sub_type ∈ {collection, evolution, key}` 或 `price_coin ≥ 200` 或 `channels ∈ {adventure_drop, system}`——任一命中永不进丢失池。
- **高级食盆 / 繁育巢穴为不限购道具**：非一次性，购买后可再次购买（解锁状态在 `pet_user_features`）。

## 8. 商城分类（12 类）

宠物蛋 / 食物 / **医疗**（新增，heal 系）/ 清洁 / 玩具 / 救援 / 扩容 / 进化 / 加速（孵化加速 + 双倍经验药）/ 洗练（属性洗练 + 特性洗练）/ 解锁 / 其他。
`sub_type` 未映射的归「其他」；新增 sub_type 须同步 `PetShopItemModel.categoryLabels` 与映射两处。

## 9. 文案与展示标准（App 面向用户）

- **禁开发腔**：用户可见文案不得出现「管理员/后台/服务端/配置/接口/数据/编码/兜底/回退」等词；异常一律转场景化文案（如「新伙伴还在路上，稍后再试试」），原始错误只进 debug 日志。
- **机制数字不揭底**：营销场景只说结果（「有机会抽中传说级宠物！」），概率/保底只在公示页。
- **金币单位转换**：`≥10万` 显示 K、`≥100万` 显示 M，**截断保留 1 位小数**（不四舍五入，K 后整数部分恒 3 位内）；达到转换阈值后金币角标可点击查看完整数额。统一走 `petGoldLabel`（`utils/pet_gold_format.dart`），禁止手写格式化。
- **机制名展示层统一「游历」（2026-10-28 定版）**：用户可见文案一律「游历/游历地/游历中」，不用「历险」；逻辑描述、字段名、错误码、流水来源值不动（`adventure` 系标识符保留）。
- 历险救援话术统一用「救援时间」，不用「自救窗口/兜底」。

## 10. 双端同步标准

- **道具图标**：`assets/pets/items/`（App）与 `public/pet-icons/`（Admin）必须同名同内容；新增道具图标双端同步落位，`tool/pet_asset_check.mjs` 为守卫。
- **长途掉落名字典**：`kLongDropNames` 须覆盖 SQL 全部 `long_only` code（服务端联查为主、字典为旧版兜底），校验工具守卫。
- **Admin 玩法内容页**：奖励/条件/掉落列一律中文转译并带道具图标（共享 `RewardCells`/`PetItemIcon`，道具目录模块级缓存）；时间线事件 12 类中文标签（`PET_TIMELINE_EVENT_META`）。
- App/Admin 常量标签值域对齐服务端（成就条件 18 值、任务条件 11 值、特性效果 11 值等），新增值域三处同步。

## 11. 服务端变更流程

- 新 SQL 一律先落 `sql/pending/`，**用户执行成功后**改状态头并移入 `sql/pet/` 归档。
- 存量函数修改用**手术式补丁**：prosrc 取回 + CR 剥离 + 锚点恰命中 N 处校验 + 防重入标记 + 自检不过即回滚；重建函数签名用 `pg_get_function_arguments`（保留参数默认值；注意其输出关键字为大写 DEFAULT，比对需 lower）。
- jsonb 深层合并用 `jsonb_set` + 内层 `||`，禁止顶层 `||` 整块替换嵌套对象。
