# 宠物模块需求标准（定版）

本档记录宠物模块**已拍板的需求口径**，是后续迭代的变更基线：改数值/口径须先更新本档再动代码。
本期定版范围：经济锚点 / 成长曲线 / 地图体系 / 健康循环 / 任务 / 成就 / 道具 / 抽奖 / 文案与展示标准 / 双端同步标准 / 服务端变更流程。

---

## 1. 经济锚点

- **蛋价四档**：N=3600 / R=12000 / SR=26000 / SSR=50000 金币。
  节奏依据：以「最大金币产出速率」计，SSR 需积攒 28 天、SR 14 天、R 7 天、N 2 天。
- **幸运蛋礼盒（抽奖）**：30000 金币/次，SSR 2%，有终身与时段限购（后台 `reserved.lottery` 配置）。
  商城卡片只出营销文案（如「有机会抽中传说级宠物！」），按钮只标价格；机制与概率数字仅在概率公示页，问号入口可达。

## 2. 成长曲线

- **升级经验 = 查表定版**（`pet_config.level_exp_table`，89 项，Admin 可调）：
  每级耗时**严格前快后慢**；常规游玩约 365 天到 90 级，高强度约 91 天。
- 取值三级：查表 → 公式（`base × growth^(level-1)`）回退 → 旧 /100 展示兜底；两端同源（summary config 下发）。
- **经验银行**：到 90 级后经验继续累积不冻结；后续上调 `level_max` 即按存量自动连升（预留扩容）。
- **每升 1 级发 `levelup_attr_points`（默认 2）可分配属性点**（`_pet_add_progress` 发放，存量已按「(level-1)×2 − 已分配」回补）。
- 旧版客户端无查表能力，按公式显示升级需求（与服务端表不一致）——服务端结算是唯一真源，旧版进度显示偏差属预期，升级以服务端为准。

## 3. 地图体系

- **72+8 图 · 20 阶**（20261025 增档）：每 5 级一阶，Lv90 星穹（19 阶）+ Lv95 源初（20 阶）各 4 图；等级上限 **100**（经验表 L90~99 沿尾部 +2.9%/级，银行存量自动连升）。
- **扩容增档**（20261025）：背包 22→28（VII~IX：1700/2400/3200）、养育 5→8（V~VII：3200/6400/12800）、寄养 10→16（VI~VIII：3200/6400/12800），价格沿各自涨价曲线。
- **时长奖励系数**（`adventure_tier_mult`，Admin 可调）：经验 **1 / 3 / 6**、金币 1 / 2.5 / 8、道具 1 / 1.2 / 1.5。
  设计哲学：经验轨与金币轨同构——**短途单位时间最赚（升级主粮），长途单次总量最大 + 稀有掉落（寻宝之旅）**。
  经验系数按定版节奏表重标（20261025 方案 B）；三档系数是一套时间比例体系，**禁止只调单档**造成每分钟效率阶梯倒挂。
- **隐藏秘境**（每系 1 图，共 18）：
  - 解锁钥匙 = 星辰罗盘（0.4% 长途掉落、80 次保底）；App 点锁定卡 → 确认弹窗 → 消耗罗盘解锁；
  - **未解锁前名称保密**（卡片只显示「未解锁的秘境」+ 收藏暗示 + 需求等级，左侧星星图标、右侧锁标）；
  - **不入推荐池**：「为你匹配」只推普通图——秘境的发现权在用户手里的罗盘，不靠系统带路（服务端 match 三处查询过滤 + App 侧双保险）。

## 4. 健康循环

- 饱食/心情**持续衰减**（历险中也衰减，寄养冻结）；展示层 60s 插值近似，服务端惰性结算为准。
- 健康：历险失败惩罚扣减；非 danger 结果归来回血（`adventure_health_recover`，默认 10）；
  **虚弱阈值 = 历险出发门槛**（默认 20），低于阈值 UI 红显、禁止出发。

## 5. 任务

- 条件类型 **11 值**（feed/interact/adventure/hatch/clean/play/heal/exchange/scene/breed/evolve）；抽取按**类别配额**保证多样性，孵化类不进日任务。
- 周任务进度从**本周首次打开页签**起算，之前的行为不追溯（口径已写入用户文案）。

## 6. 成就

- **体系树 5 线 × 4 阶**（bronze/silver/gold/legend）+ 扁平一次性成就（memorial/epic/legendary）共存。
- **渐进揭示**：前置未全部领取的节点不进列表（服务端 `PET_ACH_PREREQ_LOCKED` 兜底）。
- **运营约束**：停用任一成就树节点会使「十全十美」不可达（目标=全树节点数）——停用前须重跑 `fix_pet_collection_sink` 重算目标或恢复节点。
- **已领取的成就继续展示累计进度**（只增不减，进度快照落库）。

## 7. 道具与掉落

- 食物/治疗**按阶段步进**：进阶粮 80 / 珍馐盛宴 200 / 急救包 300（回 60 健康）/ 治愈圣泉 600（全满）；加速剂小 10 / 大 40 金。
- **掉落条目两种合法格式**：`{code,min,max,p}` 区间随机；`{p,code}` = **固定 1 件**（服务端缺省 1，不回错误）。
- **常规道具概率乘独立的 items 时长系数**（`adventure_tier_mult.items`：short=1 / medium=1.2 / long=1.5，Admin 可调，封顶 0.9）——**禁止蹭经验系数**（长途经验系数 24× 会把一切顶到封顶=必掉）。
- **掉落率基线（20261024 全线 ×0.4 定版）**：常规道具 0.25/0.10 → 0.10/0.04；星辰罗盘 1% → **0.4%**、凡品石 1.2%、珍品石 0.8%、极品石 0.4%、收藏品 2%。长途单宠单次期望：常规道具 ≈17%、罗盘 0.4%。
- **保底口径**：保底次数**不随概率缩放**，长途稀有一律 80 次未中必得；各道具独立计数，命中或达保底即得，得后清零重计。
- **积分只经「积分兑换」渠道产出**——随机事件奖励不含积分项（Admin 编辑器无积分字段）。
- **收藏品消费端（收藏兑换）**：`reserved.collection_exchange` 配方表（Admin 可调），六系收藏品各 3 档：**4 件→双倍经验药 / 6 件→进化石·极品 / 10 件→星辰罗盘**——收藏品是终极货币，罗盘可换 = 隐秘境自循环的稳定终点。App 商城在持有收藏品时出兑换卡；满包预检不扣料。
- **收藏/圆满成就**：`collection_total`（累计获得收藏品件数，流水口径）——3 件「初代收藏家」(epic) / 10 件「秘境鉴赏家」(legendary)；`tree_full_claim`（成就树已领节点数）——全部领取「十全十美」(memorial，跨线彩蛋；目标=全树节点实际数，动态口径)。
- **珍稀保护（丢物边界三规则）**：`sub_type ∈ {collection, evolution, key}` 或 `price_coin ≥ 200` 或 `channels ∈ {adventure_drop, system}`——任一命中永不进丢失池。
- **高级食盆 / 繁育巢穴为不限购道具**：非一次性，购买后可再次购买（解锁状态在 `pet_user_features`）。

## 8. 商城分类（12 类）

宠物蛋 / 食物 / **医疗**（新增，heal 系）/ 清洁 / 玩具 / 救援 / 扩容 / 进化 / 加速（孵化加速 + 双倍经验药）/ 洗练（属性洗练 + 特性洗练）/ 解锁 / 其他。
`sub_type` 未映射的归「其他」；新增 sub_type 须同步 `PetShopItemModel.categoryLabels` 与映射两处。

## 9. 文案与展示标准（App 面向用户）

- **禁开发腔**：用户可见文案不得出现「管理员/后台/服务端/配置/接口/数据/编码/兜底/回退」等词；异常一律转场景化文案（如「新伙伴还在路上，稍后再试试」），原始错误只进 debug 日志。
- **机制数字不揭底**：营销场景只说结果（「有机会抽中传说级宠物！」），概率/保底只在公示页。
- **金币单位转换**：`≥10万` 显示 K、`≥100万` 显示 M，**截断保留 1 位小数**（不四舍五入，K 后整数部分恒 3 位内）；达到转换阈值后金币角标可点击查看完整数额。统一走 `petGoldLabel`（`utils/pet_gold_format.dart`），禁止手写格式化。
- 历险救援话术统一用「救援时间」，不用「自救窗口/兜底」。

## 10. 双端同步标准

- **道具图标**：`assets/pets/items/`（App）与 `public/pet-icons/`（Admin）必须同名同内容；新增道具图标双端同步落位，`tool/pet_asset_check.mjs` 为守卫。
- **长途掉落名字典**：`kLongDropNames` 须覆盖 SQL 全部 `long_only` code（服务端联查为主、字典为旧版兜底），校验工具守卫。
- **Admin 玩法内容页**：奖励/条件/掉落列一律中文转译并带道具图标（共享 `RewardCells`/`PetItemIcon`，道具目录模块级缓存）；时间线事件 12 类中文标签（`PET_TIMELINE_EVENT_META`）。
- App/Admin 常量标签值域对齐服务端（成就条件 18 值、任务条件 11 值、特性效果 11 值等），新增值域三处同步。

## 11. 服务端变更流程

- 新 SQL 一律先落 `sql/pending/`，**用户执行成功后**改状态头并移入 `sql/pet/` 归档。
- 存量函数修改用**手术式补丁**：prosrc 取回 + CR 剥离 + 锚点恰命中 N 处校验 + 防重入标记 + 自检不过即回滚；重建函数签名用 `pg_get_function_arguments`（保留参数默认值；注意其输出关键字为大写 DEFAULT，比对需 lower）。
- jsonb 深层合并用 `jsonb_set` + 内层 `||`，禁止顶层 `||` 整块替换嵌套对象。
